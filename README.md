# pg-hotpotato

《傳炸彈》是 mobile-first 純 HTML/CSS/JS Playgrounds SAM。3–4 名玩家，本機玩家搭配 AI，炸彈爆炸時持有者淘汰，直到系列賽產生冠軍。系列：**桌遊**。

未來 Playgrounds Invite 可傳送 pass／boom 事件；目前只有本機對局。

```bash
npx --yes serve .
npx --yes vitest run
```
